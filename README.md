# SportsLink Digital

A lightweight static website for [sportslink.mt](https://sportslink.mt). It has no build step, runtime dependency, CMS, or database.

## Preview locally

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

The repository contents are intended to be served directly from cPanel's `public_html` directory. Back up the existing WordPress site before replacing it.
